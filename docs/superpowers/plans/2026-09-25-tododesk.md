# TodoDesk 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建 TodoDesk——Electron 双窗口（透明置顶桌面贴 + 全功能主程序）Windows 桌面待办应用，便携式数据目录。

**Architecture:** 主进程（CJS）持有全部数据与业务逻辑（`shared/model.js` 纯函数 + `shared/store.js` 文件 IO），两个渲染窗口（原生 ES Modules，无框架无构建）通过 preload contextBridge 的受控 IPC 读写数据，数据变更由主进程广播 `data-changed` 全量刷新。

**Tech Stack:** Electron（最新稳定版）、electron-builder（仅 dev 依赖）、node:test（内置测试器）、Python Pillow（仅一次性生成图标）。

**Spec:** `docs/superpowers/specs/2026-09-25-tododesk-design.md`（本计划依据该文档，执行者须同时阅读两份）

## Global Constraints

- 项目根：`E:\apps\TodoDesk`；依赖仅 `electron` + `electron-builder`（devDependencies），运行零 npm 依赖
- 模块体系：`src/main/`、`src/shared/`、`tests/` 用 **CommonJS**；`src/renderer/` 用 **ES Modules**（`<script type="module">`）；两侧不得互相 require
- 数据文件：`<软件目录>/data/data.json`（开发=项目根 `data\`，打包后=exe 目录 `data\`），原子写 + `.bak` 滚动备份

- 色彩令牌（亮/暗）逐字使用 spec §6.1 的 hex 值，`prefers-color-scheme` 切换；`nativeTheme.themeSource = 'system'`
- 所有 git commit 信息末尾加：`Co-Authored-By: Claude Code <noreply@anthropic.com>`
- YAGNI（spec §10）：提醒、多级分类、标签、统计、多桌面贴、云同步、导入导出、富文本、回收站、国际化一律不做

### Task 3: model.js——数据模型纯函数（TDD）

**Files:**
- Create: `src/shared/model.js`
- Test: `tests/model.test.js`

**Interfaces:**
- Produces（后续所有任务依赖，签名逐字使用）:
  - `CATEGORY_PALETTE: string[8]`（`['#2FA98C','#4A90D9','#8B7EC8','#E5A84B','#E58BB0','#3FB8C9','#7FA653','#7A8B87']`）
  - `DEFAULT_SETTINGS`（spec §3 settings 完整对象，hotkey `'Control+Alt+T'`、widgetOpacity `0.85`、widgetPosition `null`、widgetSize `null`、showCompletedInWidget `true`、widgetGroupByCategory `true`、widgetVisibleCategoryIds `[]`、widgetShowUncategorized `true`、autoLaunch `false`）
  - `createCategory({name, color, sortOrder}, now) → category`（补 id=uuid、createdAt）
  - `createTodo({title, categoryId}, todos, now) → todo`（id、notes `''`、startTime=now、endTime/dueTime `null`、endTimeManuallySet `false`、createdAt/updatedAt=now、sortOrder=`nextSortOrder(todos)`）
  - `nextSortOrder(todos) → int`（全局最大+1，空表=0）
  - `renumber(orderedIds) → [{id, sortOrder}]`（sortOrder=数组下标）
  - `isCompleted(todo)`、`isOverdue(todo, now)`、`isSameDay(iso, now)`（本地自然日）
  - `visibleTodos(todos, categories, settings, now) → {groups:[{key,category,todos[]}], completedToday:todo[](endTime 降序), activeCount}`（应用 widgetVisibleCategoryIds/未分类开关/分组；组内 sortOrder 升序；不分组时单一 key='__all__' 的组；已完成的进 active 的排除）
  - `filterTodos(todos, {status='all', categoryId='all', dateField='startTime', dateFrom=null, dateTo=null}) → todo[]`（status: all|active|completed|overdue；dateTo 含当日全天；结果按 sortOrder 升序）
  - `validateNewTodo(input) → {valid, errors[]}`（title 非空≤200；categoryId 存在或 null）
  - `validateTodoPatch(patch) → {valid, errors[]}`（只认 title/notes/categoryId/startTime/endTime/dueTime/endTimeManuallySet；时间为合法 Date）
  - `validateCategoryInput(input) → {valid, errors[]}`（name 非空≤50；color 须在 CATEGORY_PALETTE 内）
  - `applyTodoUpdate(todo, patch, now) → todo`（合并并置 updatedAt=now；**patch 含 endTime 时置 endTimeManuallySet=true**；endTime 置 null 时清该标记）
  - `seedState(now) → {categories, todos, settings}`（一个「默认」分类，color `'#2FA98C'`，sortOrder 0）
  - `id() → uuid`（`crypto.randomUUID()`）
