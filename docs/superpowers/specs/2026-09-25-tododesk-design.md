# TodoDesk 设计文档

- 日期：2026-09-25
- 状态：已与需求方逐节确认
- 平台：Windows 10/11 桌面

## 1. 产品概述

TodoDesk 是一款个人 Windows 桌面待办事项软件，由两个窗口组成：

- **桌面贴**：透明、置顶、半透明的悬浮清单，极简交互，常驻桌面
- **主程序**：普通窗口，承载全部管理功能（待办管理、分类管理、历史查看、设置）

核心时间模型：每个待办有**开始时间**（默认=创建时刻）、**完成时间**（默认=勾选完成的时刻）、**截止时间**（可选、手动填），三者均可人工调整。无提醒功能。

从零编写原创代码，只实现功能需求，不使用任何第三方软件的资源或代码。

## 2. 总体架构

```
E:\apps\TodoDesk\
├─ package.json            # 仅 dev 依赖：electron + electron-builder
├─ src\
│  ├─ main\                # Electron 主进程
│  │  ├─ main.js           # 入口：单实例锁、托盘、生命周期、数据目录解析
│  │  ├─ widget-window.js  # 桌面贴窗口（透明/置顶/无边框/可拖动）
│  │  ├─ main-window.js    # 主程序窗口（原生标题栏普通窗口）
│  │  └─ ipc.js            # IPC 通道注册与参数校验
│  ├─ shared\
│  │  ├─ store.js          # 数据层：加载/原子保存/备份恢复（纯逻辑，可单测）
│  │  └─ model.js          # 数据模型、默认值、校验规则（纯逻辑，可单测）
│  └─ renderer\
│     ├─ widget\           # 桌面贴：widget.html / widget.js / widget.css
│     └─ app\              # 主程序：index.html / app.js / app.css
├─ tests\                  # node:test 单元测试
├─ build\                  # 图标等打包资源
└─ data\                   # 便携式数据目录（gitignore，随软件目录迁移）
```

技术决策：

- **Electron**（最新稳定版）。理由：透明/置顶/无边框、全局快捷键、双窗口共享进程与数据都有原生支持；HTML/CSS 实现精致 UI 效率最高。代价是内存 ~150-250MB，已与需求方确认接受
- **无前端框架、无构建步骤**：渲染层用原生 ES Modules 直接加载，整个项目 dev 依赖只有 electron 和 electron-builder，代码透明、安装轻
- **便携式数据**：数据存 `<软件目录>\data\data.json`（+ `data.json.bak` 滚动备份），不用 %APPDATA%。搬迁 = 整个目录拷走。开发模式数据目录为项目根下 `data\`；打包后为 exe 所在目录下 `data\`。启动时检测写权限，不可写则明确报错提示更换目录，绝不静默丢数据
- **安全边界**：渲染进程通过 preload 的 contextBridge 调用受控 API，不直接访问文件系统
- **单实例**：`app.requestSingleInstanceLock()`，重复启动时激活已有实例（显示桌面贴与主程序）

## 3. 数据模型

存于 `data/data.json`，一个文件三个顶层键：`categories`、`todos`、`settings`。

```js
// 分类
{ id: string,          // uuid
  name: string,        // 非空
  color: string,       // '#rrggbb'，从预设色板选择
  sortOrder: int,      // 排序，桌面贴新建默认分类 = sortOrder 最小的分类
  createdAt: ISO8601 }

// 待办
{ id: string,
  title: string,       // 非空
  notes: string,       // 备注，可为空，默认 ''
  categoryId: string|null,  // null = 未分类
  startTime: ISO8601,  // 新建时默认 = 创建时刻，可人工调整
  endTime: ISO8601|null,    // 勾选完成时默认 = 此刻，可人工调整；null = 未完成
  dueTime: ISO8601|null,    // 截止时间，可选，手动填
  createdAt: ISO8601,
  updatedAt: ISO8601,
  sortOrder: int }     // 同一显示分组内稳定排序

// 设置
{ hotkey: 'Control+Alt+T',      // 显示/隐藏桌面贴，可改
  widgetOpacity: 0.85,          // 0.3–1.0
  widgetPosition: {x, y}|null,  // 记住桌面贴位置；null = 首次默认位置（主显示器右下角，边距 16px）
  widgetSize: {width, height}|null, // 记住桌面贴尺寸；null = 默认 300×420；最小 240×200
  showCompletedInWidget: true,  // 桌面贴是否显示当天已完成
  widgetGroupByCategory: true,  // 桌面贴是否按分类分组显示
  widgetVisibleCategoryIds: [], // 空数组 = 展示全部分类；否则只展示勾选的
  widgetShowUncategorized: true,// 桌面贴是否展示未分类待办
  autoLaunch: false }           // 开机自启动
```

关键语义：

- **完成语义（单一事实来源）**：`endTime` 有值 = 已完成，值即完成时间。「当天已完成」= endTime 落在今天（本地时区自然日）
- **取消勾选** → 清空 endTime；若该 endTime 曾被人工修改过，先弹确认再清空（防止误丢人工记录）。判定方式：待办上有一个 `endTimeManuallySet: boolean` 标记，任何通过编辑器修改 endTime 的保存动作将其置 true，取消勾选清空时检查此标记
- **时间调整自由度**：不强制 endTime > startTime 等约束，人工调整后的任何先后关系都允许
- **首次运行**：自动创建「默认」分类（薄荷青色），保证桌面贴新建总有落点
- **逾期**：dueTime 已过且未完成 → 桌面贴与主程序中用珊瑚色点/文字标识

## 4. 桌面贴（透明悬浮窗）

### 4.1 展示

- 无边框、置顶（always-on-top）、半透明圆角面板（宽约 280px，单列）；Win11 启用原生 acrylic 亚克力模糊，不支持时退回 CSS 半透明
- 条目**只显示标题文字**；按分类分组显示时每组一条小标行（色点 + 分类名）；可整体关闭分组（设置项）
- 桌面贴展示哪些分类由主程序配置（`widgetVisibleCategoryIds` + 未分类开关）
- 已完成条目划线置灰沉底，收在「已完成（今天）」折叠区，只显示当天完成的；是否显示由设置控制
- 逾期条目：珊瑚色点标识
- 鼠标悬停时面板轻微加深，便于阅读操作
- **拖动**：按住标题区/空白分组头拖动整个贴（拖动时不触发内联编辑）
- **改变大小**：拖窗口边缘或右下角手柄调整宽高（最小 240×200，最大不超所在显示器工作区）；若 Electron 透明窗口在部分平台禁用原生缩放，则退化为自绘右下角手柄方案；内容超出高度时列表区滚动
- **状态持久化**：拖动/缩放结束后（去抖 500ms）保存 `widgetPosition` 与 `widgetSize`，下次启动恢复
- 透明度在主程序设置中调节
- 全局快捷键（默认 `Ctrl+Alt+T`）显示/隐藏

### 4.2 统一内联交互（新建与修改是同一种操作）

- **新建**：点击列表空白处 → 该处出现输入行 → 输入标题 → **回车或点击其他空白处**确认；回车确认后自动出现下一个空行，可连续录入；空行失焦自动消失
- **新建落哪个分类**：点的是某分类分组内空白 → 归入该分组分类；点的是分组外空白或未开分组 → 归入 sortOrder 最小的分类
- **修改标题**：单击标题文字 → 原位变输入框 → 回车/点空白提交，Esc 取消；提交为空则放弃编辑（不产生空任务）
- **快速完成**：点勾选框，endTime = 此刻（触发唯一的全局庆祝动效：薄荷青涟漪 + 划线 + 沉底）
- **删除**：右键菜单，带确认
- **详情**：右键菜单或悬停时条目右侧「⋯」按钮打开贴内覆盖层面板（面板略加宽），可编辑：标题、备注、分类、开始/完成/截止三个时间、勾选完成/取消完成、删除任务

桌面贴上不做：分类管理、软件设置、历史查看（全部在主程序）。

## 5. 主程序（普通窗口）

原生标题栏（自动跟随系统明暗），左侧窄导航 + 右侧内容区，三个页签：

1. **待办管理**（首页）
   - 筛选：状态（全部/进行中/已完成/已逾期）、分类、日期范围（按开始或完成时间）
   - 列表列：标题、分类、开始时间、完成时间、截止时间、备注
   - 新建/编辑（表单与桌面贴详情面板同一套字段与校验逻辑）、删除、批量删除
   - **历史完成查看 = 此处按「已完成 + 日期范围」筛选**
2. **分类管理**
   - 增删改分类：名称、颜色（8 个清新预设色板）、排序
   - **配置桌面贴展示哪些分类**：全部或勾选部分；「未分类」单独开关
   - 删除分类时其下待办转为未分类（提示后执行）
3. **设置**
   - 快捷键（录制式改键，冲突时标红提示）
   - 桌面贴透明度、是否显示已完成、是否按分类分组
   - 开机自启动
   - 打开数据文件夹

顶部常驻「显示桌面贴」按钮。关闭主程序窗口 = 隐藏到托盘，桌面贴不受影响。托盘菜单：打开主程序、显示/隐藏桌面贴、退出（退出 = 整个应用结束）。

## 6. 视觉风格：「放在桌面上的薄荷便签」

清新不靠花哨：低饱和薄荷青 + 大留白；应用本身近乎无彩，颜色只留给分类色点与状态；暗色是「夜里的深杉绿」而非黑块。

### 6.1 色彩令牌

| 令牌 | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--bg` | `#F6FAF8` | `#17211E` | 主程序底色 |
| `--surface` | `#FFFFFF` | `#1E2B27` | 卡面/输入框 |
| `--ink` | `#22302B` | `#E8F1ED` | 正文 |
| `--ink-soft` | `#5C6E68` | `#9AB0A8` | 次要文字 |
| `--accent` | `#2FA98C` | `#4CC8A6` | 主操作、勾选、焦点 |
| `--accent-tint` | `#E3F4EE` | `rgba(76,200,166,.14)` | 选中底、悬停底 |
| `--danger` | `#E06A5E` | `#E57A6E` | 删除、逾期 |

- 明暗跟随 Windows：`nativeTheme.themeSource = 'system'`，监听 `nativeTheme.on('updated')`，样式全部走 CSS `prefers-color-scheme`，系统切换即时生效
- 分类预设色板（8 色）：薄荷青 `#2FA98C`、天空蓝 `#4A90D9`、雾紫 `#8B7EC8`、杏黄 `#E5A84B`、樱粉 `#E58BB0`、石青 `#3FB8C9`、橄榄绿 `#7FA653`、石墨灰 `#7A8B87`

### 6.2 字体与形态

- 字体栈：`"Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI", sans-serif`；不引入网络字体（离线、秒启动、原生融入）。正文 14px，桌面贴条目 13px，分组小标 12px；时间数字用 `font-variant-numeric: tabular-nums` 对齐
- 形态：圆角 10–12px，发丝边框（`--hairline`: 亮 `#E3EBE7` / 暗 `#2A3A34`），极轻投影；列表行高宽松（~40px）像便签不像报表；全部左对齐
- 动效：唯一庆祝动效 = 勾选完成（涟漪 + 划线 + 沉底 ~400ms）；其余仅展开/收起 150ms、悬停渐变；尊重系统「减少动态效果」设置

## 7. 错误处理

- **写入**：原子写（写 `data.json.tmp` → rename 覆盖）；每次成功保存后将旧文件滚动为 `data.json.bak`
- **加载**：主文件损坏 → 用 `.bak` 恢复并托盘提示；两者均损坏 → 报错对话框，原文件保留不动（改名 `.corrupt` 留证），以空数据启动但**不自动覆盖写**，用户确认后才继续
- **启动**：数据目录写权限检测失败 → 明确报错引导换目录
- **校验**：IPC 层校验字段类型与枚举；时间必须为合法 ISO8601；未知字段忽略（向前兼容）
- **桌面贴多屏恢复**：启动/显示时用 `screen.getAllDisplays()` 校验保存的窗口矩形（位置+尺寸）：
  - 与某显示器工作区有交集 → 落在该显示器，并把越出工作区的部分收回（保证完全可见）
  - 不与任何显示器相交（如拔掉外接屏、改了排列）→ 定位到主显示器工作区右下角（边距 16px），尺寸超出时收缩到工作区内
  - DPI 缩放变化时 Electron 使用逻辑坐标（DIP），天然兼容，不做额外换算
- **快捷键注册失败**（被占用）→ 托盘提示，主程序设置页标红，可改键
- **运行日志**：主进程关键错误写入 `data/log.txt`（追加、按大小轮转 1MB），便于排查

## 8. 测试策略

- **单元测试**（`node:test`，零额外依赖）：`model.js`（默认值生成、完成语义、校验规则、分类配置过滤逻辑）、`store.js`（原子写、备份滚动、损坏恢复、写权限失败路径）
- **手工冒烟清单**（真实运行）：首建默认分类；桌面贴三种核心操作（打字回车新建/点标题改名/点勾完成）；连续录入；勾选后当天折叠区出现；取消勾选人工改过的时间弹确认；快捷键显隐；明暗主题切换即时生效；桌面贴拖动/缩放后重启恢复；保存位置后在多屏间拔插显示器，桌面贴自动回到可见区域；打包便携版在干净目录运行
- 不引入 E2E 框架

## 9. 打包分发

- electron-builder 产出 **目录版便携应用**（无安装器；注意不用单 exe 的 portable 目标——它每次运行解压到临时目录，会破坏「data 在 exe 旁」的便携模型）
- 应用图标：薄荷青底白色对勾圆角方块（`build/icon.ico`，256px 多尺寸）
- 不做安装器、不做自动更新（YAGNI）

## 10. 明确不做（YAGNI 清单）

提醒/通知推送、多级分类、标签、统计报表、多桌面贴、云同步、多设备、导入导出、富文本备注、回收站、国际化（界面仅中文）。

## 附录：IPC API 概要（preload contextBridge 暴露）

```
todoDesk.categories.list() / create({name,color}) / update(id,{...}) / remove(id)
todoDesk.todos.list(filter?) / create({title,categoryId?}) /
             update(id,{title?|notes?|categoryId?|startTime?|endTime?|dueTime?}) /
             complete(id) / uncomplete(id) / remove(id)
todoDesk.settings.get() / set(patch)
todoDesk.widget.show() / hide() / toggle()
todoDesk.openDataFolder()
```

所有写操作在主进程 `ipc.js` 校验后落库，数据变更后主进程向两个窗口广播 `data-changed` 事件，渲染层各自重渲染。
